# Replaceable native mobile frontend (planned)

The release targets are actual installable iOS and Android apps with a compatible C# runtime and native GPU adapters. The renderer framework is not yet selected. It must compile and execute the exact new C# game core; no WebView workaround or separate gameplay algorithms.

Prove iOS and Android compilation, launch, touch, scene feed consumption, memory, thermal/performance and background/resume early. A Pages demo does not satisfy a native release gate.

Rendering remains primitive geometry with explicit HEX colors until the full first Hunt and engine gates pass.
