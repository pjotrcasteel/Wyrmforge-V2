# Fire Hunt material review

Nine 64 × 64 albedo tiles for the V2 material lab. Inspect them at the default Hunt scale first. The tile and repeat views are for inspecting the pixel structure and the seam.

The first seven source studies were generated for V2. The woodland palette and surface character follow the [V1 Wet Forest ground studies](https://github.com/pjotrcasteel/Wyrmforge/tree/2b401722164b2d34a0ee4388869d64555e1306c8/user_handover_files/concepts/arena-v2/wet-forest/ground-materials/v1) and [V1 Arena references](https://github.com/pjotrcasteel/Wyrmforge/tree/2b401722164b2d34a0ee4388869d64555e1306c8/user_handover_files/concepts/Arena). V2 review tiles use reduced detail and contrast on walkable ground. The two additional alternatives are a shaded moss grade and a darker cross-grain cliff treatment.

The straight and broken trail boundaries are fixed geometry studies. Craters use the V2 edit ledger. This first set is for visual review; later Fire Hunt ground, emissive lava, and animated flow are separate stages.
