# Wet Forest live trees

Exact live tree pixels and root anchors from Wyrmforge V1's Gothic Forest Kit,
repacked into a small tree-only atlas. Source commit
`2b401722164b2d34a0ee4388869d64555e1306c8`, atlas blob
`7406de190d4dd626d7d6a8deb68a83fd651ff4df`.

Gothic Forest Kit is based on Pixel Crawler Free Pack 2.11 by Anokolisa,
recoloured for Wyrmforge. Original source credits are in the V1 repository
under `art/source/environment/forest/README.md`.
