# Wyrmforge V2

Independent, clean-room voxel engine laboratory. No Wyrmforge V1 code, assets, runtime dependencies, or deployment pipeline.

## Development

Serve this repository as static files (for example, `python -m http.server 8000`) and open `index.html`. Run tests using `node --test tests/*.test.mjs`.

GitHub Pages will publish from this repository only. No changes to V1 are required.
